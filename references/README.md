# Local reference files

Source proposals and architectural drawings are stored under `references/private/` and excluded from the public repository. This avoids publishing the original building documents while preserving local traceability for grid reconstruction.

The local reference set may include:

- `FinalProjectProposal.pdf`
- the later hand-drawn floor-plan images in `floorplans_20261116/`
- the revised Floor 11 drawing included with the hand-drawn plan set

The superseded venue-plan deck and earlier extracted map images were removed during the final cleanup. The active model follows the later hand-drawn floor plans and the revised Floor 11 plan. Floor 12 is a user-directed derivation of Floor 11 until an independently verified Floor 12 drawing is supplied. Derived grids record source and uncertainty information in `data/geometry_evidence.csv` without copying private source files into Git.
